SpotImport · Fusión local

Uní tus bibliotecas de Spotify

Importá los archivos de datos de tus cuentas, elegí playlists y canciones guardadas, quitá duplicados y prepará una lista final. No hace falta conectar Spotify Developer.

Cómo funciona esta versión: los archivos se procesan en tu navegador; no se suben a ningún servidor de SpotImport. Spotify no permite crear una playlist en tu cuenta sin acceso autorizado a su API, así que esta versión prepara un CSV/JSON con la selección para que la puedas conservar o usar para importarla con una herramienta compatible. Para comparar contra Main, importá también los datos de esa cuenta.

Acepta ZIP de exportación de Spotify o archivos JSON individuales. Para obtenerlos, solicitá una copia en Privacidad de Spotify. La exportación puede tardar en llegar. Los enlaces públicos intentan leer la lista visible del reproductor web de Spotify mediante un servicio intermediario. Puede fallar o devolver solo una parte de los temas (habitualmente hasta unos 50); si pasa, usá ZIP/JSON.
